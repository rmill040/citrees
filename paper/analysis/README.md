# Analysis builders

Every script here regenerates a table or figure from tracked inputs
(`paper/results/*.parquet`, `paper/results/tables/*.csv`, or S3 artifacts).
Outputs land in `paper/results/tables/` (untracked unless allowlisted in
`.gitignore`) or `paper/arxiv/figures/`. Run any script with `--help`.
